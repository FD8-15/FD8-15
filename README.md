**Multi-company ERP backend** for inventory, purchases, sales, payments and receipts.

**Built with:** Node.js · Express 5 · PostgreSQL · JWT · Vitest · Supertest

Highlights:

* Multi-company architecture
* Company-level data isolation
* Role-based access control
* Purchase and sales workflows
* Automatic stock management
* Transactional voucher operations
* Payment and receipt outstanding checks
* Integration testing
